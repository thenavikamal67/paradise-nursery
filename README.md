
# Paradise Nursery

Paradise Nursery is an online plant shopping application built using React, Redux Toolkit, and CSS.

## Features
- Browse houseplants in different categories.
- View plant names, images, and prices.
- Add plants to the shopping cart.
- Increase or decrease plant quantities.
- Remove plants from the cart.
- View the total price and item count.
- Navigate between Home, Plants, and Cart pages.

## Technologies Used
- React
- Vite
- Redux Toolkit
- React Redux
- CSS
- JavaScript

## Installation

1. Clone the repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL displayed in the terminal.
